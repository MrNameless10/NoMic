# Changelog

All notable user-facing changes to PrivateMic are documented here. The project uses Semantic Versioning and keeps unreleased work at the top.

## Unreleased

### Added

- Automated macOS build and unit-test checks for pushes and pull requests.
- Tag-driven GitHub Releases with a verified DMG and SHA-256 checksum manifest.
- Contribution, issue, security, branching, and release documentation.

## 1.0.0

### Added

- Native macOS menu-bar microphone mute control.
- Configurable global shortcut and input-device selection.
- Native mute with verified input-volume fallback.
- Per-device saved volume restoration and device-change monitoring.
- Optional local notification, sound, speech, and menu-bar icon feedback.
- Launch at Login through `SMAppService`.

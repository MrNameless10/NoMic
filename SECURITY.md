# Security policy

## Supported versions

Security and privacy fixes are provided for the latest published PrivateMic release.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** form to open a private GitHub Security Advisory. Do not publish exploitable details, credentials, private audio, or personal information in a public issue.

Include the affected PrivateMic and macOS versions, a concise impact description, and safe reproduction details. Reports will be acknowledged as soon as practical. A public advisory or fix will be coordinated after the issue is understood and remediation is available.

PrivateMic does not request or need seed phrases, wallet private keys, account credentials, or captured microphone audio. Never send those items with a report.
